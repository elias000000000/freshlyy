# Freshly 🥦

KI-gestützte Lebensmittelverwaltung für Schweizer Supermärkte.

## Features
- Kassenzettel mit Kamera scannen (KI erkennt Lebensmittel automatisch)
- Vorrat verwalten mit Ablaufdatum-Tracking
- KI-Rezepte aus vorhandenen Zutaten generieren
- Eigene Rezepte erstellen

## Deployment

### Vercel (empfohlen, kostenlos)
1. vercel.com öffnen
2. Mit GitHub einloggen
3. Dieses Repo importieren
4. Deploy klicken — fertig

### Lokal starten
```bash
npm install
npm run dev
```
